# GoHighLevel mapping (only if you already pay for GHL)

Same funnel, GHL vocabulary. Starter plan ($97/mo) is enough; the funnel builder, email, and automations are all included. Email sends and any SMS are billed by usage on top.

| systeme.io term | GHL equivalent | Notes |
|---|---|---|
| Funnel | Sites → Funnels | Build the seven steps in one funnel. |
| Product | Payments → Products | Create the three products; attach the PDF via a "file download" custom field or host the PDFs on Google Drive with "anyone with the link" and put the links on the thank-you page. |
| Order bump | Funnel step → Products → "Add order bump" | Same copy. |
| Upsell / downsell | Funnel steps of type "Upsell" and "Downsell" | One-click upsell requires Stripe or NMI connected under Payments → Integrations. |
| Tag | Contacts → Tags | Same tag names. |
| Automation rule | Automation → Workflows | One workflow per rule; triggers "Form submitted," "Order submitted," "Payment received," "Refund." |
| Campaign | Workflow with "Wait" steps | Build the four sequences as workflows with waits between emails. |
| Blog | Sites → Blogs | Same articles. |
| Abandoned cart | Workflow trigger "Order form submitted" with condition "Payment received = no" after 4-hour wait | |

## GHL-specific advantages worth using
- **SMS follow-up** is possible in GHL. Do not use it here. A text message about a dead parent from an unknown number is the fastest way to a complaint. Email only.
- **Calendar and pipelines** are unnecessary for a $27 product. Leave them off so the account stays simple.
- **Snapshot**: once built, save the sub-account as a snapshot so the same funnel can be cloned for a second niche.

## Cost sanity check
At $27 AOV base and roughly $36 with bump and upsell, GHL's $97/mo needs about three sales a month just to cover the platform, before ad spend. systeme.io's free plan needs zero. Choose GHL only if the account already exists for other reasons.
